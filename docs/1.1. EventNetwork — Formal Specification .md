## EventNetwork — Formal Specification

### Definition

An **EventNetwork** is a **directed acyclic graph (DAG)** whose nodes represent **immutable semantic events** and whose edges represent **semantic derivation relationships**.

The EventNetwork models **how meaning is constructed and stabilized over time**, not causal explanation.

Its primary purpose is to encode **semantic contribution** — how observed facts and previously derived meaning combine into higher-level semantic state.

---

### Core Invariants

1. **Immutability**

   Once an event is added to the EventNetwork, it MUST NOT be modified.

2. **Append-only construction**

   All externally introduced events are added as **leaf nodes**.

   Non-leaf nodes are created exclusively through **semantic derivation**.

3. **Temporal consistency**

   An event may only be derived from events that already exist in the network.

4. **Acyclicity**

   No derivation may introduce cycles.

   The EventNetwork is always a DAG.

---

### Bottom-Up Semantic Derivation Model

The EventNetwork is constructed **strictly bottom-up**:

* **Leaf events** represent externally observed or system-emitted facts (including probabilistic signals).
* **Derived events** represent semantic interpretations constructed from existing events.
* Derived events may themselves participate in further derivations, forming multi-level semantic abstraction.

Traversal is **not causal**.

The network is traversed upward to explain **how meaning was assembled**, not why an event occurred.

---

### Structural Direction vs. Semantic Lineage

The EventNetwork distinguishes between:

* **Structural edge direction**
  The physical orientation of edges in the graph.

* **Semantic derivation direction**
  The conceptual flow of meaning from contributing events toward derived semantic state.

These directions are intentionally **not equivalent**.

A derived event is considered a **semantic parent** of the events from which it was derived, regardless of structural representation.

This separation is fundamental to ensuring that **semantic explanation remains stable and replayable**, even as the network grows.

---

### Terminology and Traversal Semantics

All traversal operations are defined in terms of **semantic derivation**, not raw edge direction.

---

#### Children (Derivation Sources)

Events that directly contributed to the derivation of an event.

* Represent semantic evidence.
* Structurally represented as inbound edges.

> Querying an event for its children returns the semantic inputs used to derive it.

---

#### Parents (Derived Semantic Events)

Derived events that were created using a given event as input.

* Represent semantic aggregation and abstraction.
* Exist at a higher derivation level.

---

#### Ancestors (with maxDepth)

All higher-level semantic interpretations reachable by recursively traversing parents upward.

* `maxDepth = 1` returns direct semantic parents.
* Larger depths reveal progressively higher abstraction layers.

---

#### Descendants (with maxDepth)

Lower-level events that contributed (directly or indirectly) to an event.

Descendants are accessed through children traversal and represent **semantic evidence**, not interpretation.

---

#### Siblings

Events that share at least one common semantic parent.

* Siblings contributed to the same derived meaning.
* The relationship is semantic, not causal.

---

#### Peers

Events that occupy the same semantic role **at the current derivation frontier**, without requiring shared ancestry.

* Peers are typically:

    * parentless,
    * type-aligned,
    * domain-aligned.

Peers exist to support reasoning under **partial observability**, where higher-level meaning has not yet stabilized.

---

#### Cousins (with maxDepth)

Events related through **shared derivational ancestry**, but not direct contribution.

Cousins express **contextual semantic proximity**, emerging from similar meaning-construction pathways rather than direct evidence.

---

### Derived Context Propagation

Derived events implicitly extend the semantic context of the EventNetwork.

Once derived, an event may act as **semantic context** for subsequent derivations and pattern recognition, even when it is not a direct structural ancestor.

This enables:

* semantic propagation across derivation levels,
* multi-level pattern recognition,
* stabilization of meaning across time.

---

### Memory Implications (Non-Normative)

The bottom-up derivation model allows memory to be associated with:

* derivation structures,
* repeated semantic motifs,
* stabilized meaning patterns,

rather than with individual events alone.

This supports **structural memory**, enabling efficient recurrence detection and semantic stabilization without mutating event data.

---

### Summary

The EventNetwork is a **semantic derivation DAG** in which:

* events are immutable observations or interpretations,
* meaning flows upward through explicit derivation,
* semantic lineage is distinct from structural representation,
* higher-order relationships emerge through shared derivational structure.

This model prioritizes **semantic stabilization and explainability** over causal attribution.
